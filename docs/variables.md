# Параметры

## Обязательные для рабочего сценария

| Параметр | Где | Назначение |
|---|---|---|
| `listenHost` | SquadJS | В контейнере используется `0.0.0.0`; порт доступен только сети Dokploy. |
| `listenPort` | SquadJS | Внутренний порт экспортёра `32080`. |
| `serverId` | SquadJS | Уникальное целое число сервера. |
| `serverCode` | SquadJS и `site/config.js` | Стабильный уникальный код, например `server-1`. |
| `serverName` | SquadJS | Точное запасное имя сервера до получения `ShowServerInfo`; также используется для ссылки SquadBrowser. |
| `squadbrowserApiKey` | только SquadJS | Секретный ключ. Никогда не переносится в GitHub Pages. |
| `corsOrigins` | SquadJS | Точные источники страницы, например `https://OWNER.github.io`, без пути репозитория. |
| `snapshotUrl` | `site/config.js` | Полный HTTPS-адрес `<pathPrefix>/snapshot`. |
| `joinLinkUrl` | `site/config.js` | Полный HTTPS-адрес `<pathPrefix>/join-link`. |
| `priority` | `site/config.js` | Чем меньше число, тем раньше сервер выбирается для сида. |
| `maxSeedPlayers` | `site/config.js` | Порог рассида. При значении `80` сервер исключается из точки сбора начиная с 80 игроков. |

Для PHEX источник Pages — `https://phex-squad.github.io`. Путь `/autoseed` в
`corsOrigins` не входит.

## Значения с безопасными стандартными настройками

| Параметр | Стандартное значение | Когда менять |
|---|---:|---|
| `pathPrefix` | `/v1/autoseed` | При нескольких экспортёрах за одним доменом или конфликте маршрутов. |
| `isSeedCandidate` | `true` | `false` для сервера, который нужно только показывать. |
| `staleAfterMs` | `90000` | Увеличить только при заведомо редких обновлениях SquadJS. |
| `rateLimitWindowMs` | `60000` | Окно ограничения запросов. |
| `rateLimitMaxRequests` | `120` | Уменьшить при публичной нагрузке, учитывая частоту страницы. |
| `refreshIntervalMs` | `15000` | Частота резервного опроса страницы. |
| `staleAfterMs` страницы | `90000` | Должно быть не меньше значения экспортёра. |
| `maxSeedPlayers` | `80` | Менять только при согласованном изменении правила рассида. |

## Переменные развёртывания PHEX

Все значения находятся только в настройках двух сервисов Dokploy.

| Переменная | Назначение |
|---|---|
| `INSTANCE_NAME` | `phex-1` или `phex-2`. |
| `SQUAD_HOST` | Адрес игрового хоста. |
| `SQUAD_QUERY_PORT` | Query-порт конкретного сервера. |
| `SQUAD_RCON_PORT` | RCON-порт конкретного сервера. |
| `SQUAD_RCON_PASSWORD` | RCON-пароль конкретного сервера. |
| `SQUADBROWSER_API_KEY` | Общий ключ SquadBrowser API. |

Тома игрового хоста контейнерам не нужны: профиль Phoenix получает состояние
по RCON и не читает журналы.

## Что не является параметром страницы

Страница не должна знать:

- RCON-адрес и пароль;
- токен Discord;
- ключ SquadBrowser;
- строку подключения к базе;
- SteamID/EOSID игроков;
- внутренний адрес процесса SquadJS.

Если такое значение требуется клиентскому JavaScript, граница безопасности выбрана неверно: добавьте узкий публичный маршрут на серверной стороне.
