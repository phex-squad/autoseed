# Развёртывание PHEX

## Целевая схема

Два отдельных сервиса Compose на основном узле Dokploy используют один образ
`ghcr.io/phex-squad/squadjs:main`. Один запускается как `phex-1`, второй как
`phex-2`. Оба устанавливают исходящее TCP-соединение с игровыми RCON-портами.
Dokploy завершает TLS и направляет каждый публичный путь на внутренний порт
экспортёра.

Точные адреса, порты, пути монтирования и секреты хранятся только в Dokploy.
Публичный репозиторий страницы содержит лишь итоговые HTTPS-маршруты.

## Предварительные условия

- создан форк `phex-squad/squadjs`, а исполнитель добавлен соавтором;
- опубликованный пакет GHCR доступен Dokploy;
- с основного узла Dokploy доступны RCON-порты обоих игровых серверов;
- RCON-пароли обоих серверов доступны исполнителю из закрытых конфигураций
  хоста и переносятся напрямую в Dokploy без вывода в журналы;
- для полной работы кнопки входа выдан ключ SquadBrowser;
- у владельца `phex-squad/autoseed` есть право включить Pages.

Ключ SquadBrowser не блокирует снимки: без него `join-link` штатно отвечает
`503`, а состояние серверов продолжает публиковаться.

## Выпуск серверной части

1. В `phex-squad/squadjs` выполнить `npm run check` и проверочную сборку образа.
2. Отправить `main` и дождаться успешной публикации GHCR.
3. Создать два сервиса Compose в проекте Phoenix на основном узле Dokploy.
4. Передать каждому сервису его имя экземпляра, адрес/порты Squad, RCON-пароль
   и при наличии ключ SquadBrowser.
5. Создать два HTTPS-маршрута к внутреннему порту `32080`.
6. Проверить для обоих сервисов:
   `/livez`, `/readyz`, `/v1/autoseed/snapshot`.
7. Проверить CORS с `Origin: https://phex-squad.github.io`.
8. После появления ключа проверить `/v1/autoseed/join-link` и схему `steam:`.

## Выпуск страницы

В [`site/config.js`](../site/config.js) для каждого экспортёра заполняются
полные HTTPS-адреса:

```text
https://ПУБЛИЧНЫЙ_МАРШРУТ/v1/autoseed/snapshot
https://ПУБЛИЧНЫЙ_МАРШРУТ/v1/autoseed/join-link
```

После `npm test` владелец выбирает `Settings → Pages → GitHub Actions`, затем
повторно запускается процесс `Проверка и публикация Pages`.

## Приёмка

- оба `readyz` отвечают `200`;
- оба `snapshot` свежие и содержат ожидаемые `phex-1`/`phex-2`;
- `Access-Control-Allow-Origin` равен
  `https://phex-squad.github.io`;
- страница показывает игроков, очередь, карту и рекомендуемый сервер;
- `join-link` возвращает `steam:`-ссылку и не раскрывает ключ;
- секреты отсутствуют в Git, Pages и журналах развёртывания.

## Резервный вариант

Каталоги `overlay/` и `deploy/` сохраняют ранее проверенный запуск с чтением
журналов без контейнеров. Он не запускается одновременно с Dokploy и
используется только как осознанный откат.
