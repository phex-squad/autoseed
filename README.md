# Автосид PHEX

Единая страница сообщества PHEX показывает состояние двух серверов Squad и
подсказывает, какой из них сейчас нужно поднимать общим сидом. Репозиторий
содержит и статическую страницу GitHub Pages, и безопасный экспортёр для
SquadJS.

## Текущее состояние

| Часть | Состояние |
|---|---|
| Страница PHEX, логотип и мобильная вёрстка | готово |
| Выбор сервера по свежести, доступности и приоритету | готово |
| Конфигурации PHEX №1 и №2 без секретов | готово |
| Node.js 24 LTS и зависимости SquadJS на хосте | установлены и проверены |
| Запуск двух экземпляров через PM2 | готово |
| GitHub Pages | включается владельцем после первой отправки `main` |
| RCON, чтение журналов и ключ SquadBrowser | ожидают значения и права владельца |
| Домен, сертификат и маршрут Nginx к экспортёрам | ожидают решения владельца |

Страница не подменяет отсутствующие данные вымышленным состоянием. Пока
экспортёры не подключены, обе карточки честно показывают этап настройки.

## Проверка

Требуется поддерживаемая версия Node.js 24 LTS.

```bash
npm test
```

Проверки не используют сеть и секреты. Они проверяют выбор сервера, отсутствие
секретов в публичной части, безопасную повторную установку, шаблоны PHEX и
закреплённые версии GitHub Actions.

## Публикация страницы

1. Открыть `Settings → Pages`.
2. В `Build and deployment → Source` выбрать `GitHub Actions`.
3. Запустить процесс `Проверка и публикация Pages` или отправить изменение в
   `main`.
4. После выдачи домена экспортёра заменить пустые адреса в
   [`site/config.js`](site/config.js) и проверить CORS.

Ожидаемый адрес страницы:
`https://phex-squad.github.io/autoseed/`.

## Безопасность

- Ключ SquadBrowser и RCON-пароли не передаются браузеру и не хранятся в Git.
- Экспортёры слушают только `127.0.0.1`; наружу их публикует Nginx по HTTPS.
- В публичном снимке нет SteamID/EOSID.
- При ошибке сертификата запрос к SquadBrowser не повторяется с отключённой
  проверкой TLS.
- Установка не перезаписывает отличающиеся файлы SquadJS без явного `--force`.
