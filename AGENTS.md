# Контекст проекта

Проект — публичная страница автосида PHEX. Главная цель — короткий и
проверяемый путь от двух экспортёров SquadJS в Dokploy до рабочей GitHub Pages
без публикации RCON-паролей, ключей, карты хоста и данных игроков.

## Состав

- `site/` — статическая страница GitHub Pages;
- `overlay/`, `deploy/`, `scripts/install.sh` — сохранённый переносимый
  вариант для хоста без контейнеров; в боевом контуре не используется;
- `test/` — проверки выбора сервера, поставки и развёртывания.

## Правила изменений

- Рабочий язык — русский, англицизмы использовать только в именах технологий и
  программных интерфейсов.
- Боевая серверная часть живёт в отдельном форке `phex-squad/squadjs`;
  конкретные адреса, порты, пути монтирования и секреты хранятся только в
  Dokploy.
- В `site/` допустимы только публичные HTTPS-адреса экспортёров.
- Страница не получает ключ SquadBrowser: ссылку Steam выдаёт серверный маршрут
  `join-link`.
- До отправки изменений выполнять `npm test`.
- Изменения публичного договора экспортёра требуют синхронной проверки с
  `phex-squad/squadjs` и обновления `SOURCE.md`.
