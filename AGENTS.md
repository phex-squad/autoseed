# Контекст проекта

Проект — публичная страница автосида PHEX и переносимая серверная часть для
SquadJS. Главная цель — короткий и проверяемый путь от пустого хоста до рабочей
страницы без публикации RCON-паролей, ключей и данных игроков.

## Состав

- `site/` — статическая страница GitHub Pages;
- `overlay/` — экспортёр и его зависимости для совместимой сборки SquadJS;
- `deploy/` — шаблоны двух экземпляров PHEX, подготовка Node.js, PM2 и Nginx;
- `scripts/install.sh` — безопасная установка `overlay` в checkout SquadJS;
- `test/` — проверки выбора сервера, поставки и развёртывания.

## Правила изменений

- Рабочий язык — русский, англицизмы использовать только в именах технологий и
  программных интерфейсов.
- Секреты хранятся только в `/opt/squadjs_ostw/deploy/.env` с правами `0600`;
  этот файл не отслеживается Git.
- В `site/` допустимы только публичные HTTPS-адреса экспортёров.
- Страница не получает ключ SquadBrowser: ссылку Steam выдаёт серверный маршрут
  `join-link`.
- До отправки изменений выполнять `npm test`.
- Изменения `overlay/` требуют обновления `SOURCE.md` и отдельной проверки
  совместимости с SquadJS.
