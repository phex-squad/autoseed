# История выпусков

## Не выпущено — PHEX

- Фирменная страница PHEX для двух серверов с честным состоянием настройки.
- Логотип и палитра сообщества без внешних ресурсов.
- Шаблоны двух экземпляров SquadJS, безопасная подстановка секретов и PM2.
- Установка Node.js 24 LTS в каталог пользователя с проверкой SHA-256.
- Пример узкого HTTPS-маршрута Nginx и пошаговая инструкция боевого запуска.

## 0.1.0 — 2026-07-26

- Переносимый `AutoseedExporter` с зафиксированной версией источника.
- Безопасный пример настройки SquadJS без значений секретов.
- Минимальная страница GitHub Pages с проверкой свежести и приоритетом серверов.
- Получение Steam-ссылки только через серверный `join-link`.
- Скрипт установки с защитой от неявной перезаписи.
- Автоматическая проверка чистой и повторной установки.
- Процесс проверки и публикации Pages с закреплёнными ревизиями Actions.
